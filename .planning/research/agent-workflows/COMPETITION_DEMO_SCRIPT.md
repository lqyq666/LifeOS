# 3–5分钟演示脚本与证据边界
当前可执行开发演示：在仓库运行 npx tsx scripts/workflow-demo.ts。输出 evidence/DEMO_RUN.json 和 DEMO_SIMULATED_TRACES.jsonl。另运行 scripts/workflow-verify.ps1，可复现真实SDK/隔离PG/合成Provider跨3会话测试。画面应始终显示“合成学生；本地候选；云候选未运行”；当前未录制比赛成片。

0:00–0:40 同一位合成大三学生每周6小时，想比较就业/考研/独立开发。唯一主伙伴先呈现快速方案。深入选择界面尚未上线，本段以开发演示输入展示，不伪装产品UI。
0:40–1:30 展开真实本地3分析并行→约束检查→独立审查→综合trace；Provider明确标“模拟”。展示为何无法三条高强度并行、先核实一个可改变判断的信息。候选proposed，不宣称目标已保存。
1:30–2:40 学生接受联系学长→发出三天未回→拒绝继续。同一event三会话，展示G2_MAIN_ENTRY真实隔离PG回执accepted/waiting_result/declined；未回原因未知，拒绝后停止；没有第二次模型调用。
2:40–3:20 单次有偿设计示例：只说明该次交付与付款。展示确定性growthDiff的来源与未知；清楚标“星图UI未集成”，不剪接成已发生的身份升级。
3:20–4:00 展示权限/撤回/费用/取消失败证据和最终Gate。云项目只读版本可见，但没有本候选云运行；真实学生价值和真实盲配对仍待验收。
正式比赛成片须等G3云候选、G4星图和真实用户链完成后补录，不能用这份开发脚本宣布完整比赛证据通过。
