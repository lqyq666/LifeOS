# Brief: 星图主要关键词与经历摘要

**日期：** 2026-10-17
**状态：** Locked

## 问题

星图目前把置顶后的最近三个主题直接作为主节点。更新时间不能证明主题更重要，新近但证据薄的主题可能挤掉有多段经历支持的主题。经历详情保留原话、行动和结果，但阅读态没有把这些字段组织成可复盘的摘要。

## 决定

在现有 `user_themes`、`experience_theme_links` 和 `experiences.content` 上做确定性投影：

1. 三个主要关键词依次尊重本人置顶、本人明确优先、已确认经历数、关联经历数、独立本人来源数和当前状态；最后才以更新时间打破平局。
2. 每个关键词展示入选依据，避免把系统排序伪装成本人自我定义。
3. 经历摘要固定呈现本人做了什么、已报告结果、本人反思和仍未知项；只复用已存原话字段，不新增推断或模型调用。
4. 更正、撤销、来源校验、模式确认门和现有四工作流、六个 Skill 保持不变。

## 参考结论

- Graphiti：派生实体和关系应追溯到原始 episode，并保留时间与来源。
- LangMem：episodic memory 用一致结构记录情境、行动和结果，价值在于后续检索和复用，而不是生成抽象标签。
- GraphRAG：汇总多个描述时保留完整上下文，结论只能来自提供的数据并附记录依据。
- Mem0：记忆更正应更新原记录及元数据，并在更新后重新验证读取结果。

## 验收

- 新近、无经历支持的主题不会仅凭更新时间进入前三。
- 本人置顶和明确优先仍高于系统证据排序。
- 每个主要关键词都有可解释的入选依据。
- 经历摘要不把未报告结果写成成功，不把单次行为写成稳定能力。
- 受影响纯函数、星图后端、类型检查和生产构建通过。
