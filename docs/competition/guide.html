02 / 首次使用：完成一段连续体验

1. 打开并进入对话。 打开正式对话页，点击“登录”，使用已开通的邮箱和密码登录。首页也可登录后选择“继续对话”，认知空间可选择“聊聊”。预期：出现“退出登录”，输入区域下方显示账户保存或资格信息。若提示维护，请稍后查看交付状态说明。

2. 从一件真实小事开始。 在消息输入框填写下列示例，点击“发送消息”。预期：收到围绕该经历的回复或具体追问；无需先选定职业或升学路线。

示例输入：我还没想好毕业后往哪走，最近整理课程资料时发现自己愿意把零散内容分成几类。先帮我从一个具体问题开始。

3. 补充自己的条件。 回答实际追问，再补充偏好、可用时间和限制。预期：讨论逐步使用你提供的依据，信息不足处继续保留未知；无需一次说完。

示例输入：我更喜欢资料整理和排版，编程经验不多。这周只有两小时，先不考虑付费课程，也不急着决定考研还是就业。

4. 要一个愿意尝试的行动或草稿。 可以要求缩小投入、直接给成品或修改表达。预期：得到具体起点或材料；不合适时可以拒绝。

示例输入：先帮我想一个20分钟内能完成的小尝试。如果需要联系别人，请先写草稿，不要替我发送。

5. 刷新并继续反馈。 等最终回复和保存完成后刷新；手机可先展开侧边栏，选择原对话。预期：已保存内容仍可查看。若未看到结果，先回到原对话核对，再决定是否重发。

示例输入：我已经把资料导出成PDF，对方说手机打不开，还没有读到内容。先帮我处理这个问题，不要认定对方不感兴趣。

以上“预期”是操作指引，不是本次公网验收结论；实际已验证范围以《交付状态》为准。

03 / 核心功能与用户控制

没有明确目标，也能开始。 描述一件最近的事或一个具体困扰，例如课程、竞赛、社团、实习或休息安排；也可以说“我只想聊聊，先别安排任务”。

梳理方向和个人依据。 围绕升学、就业等选择，说清本人偏好、已有经历和现实约束。可以追问“这个判断依据我说过的哪件事？还有什么未知？”外部资格与政策仍需核对当前官方要求。

把目标落到可承担的一步。 明确本周可用时间和精力；觉得太多时直接说“缩小到今天20分钟”“本周没有时间，先暂停”。建议由你决定是否采用。

生成、改写并继续使用材料。 直接提出要写的内容、对象与事实边界；随后说“把刚才那段改短，保留本人贡献”。核对草稿后再自行复制和使用。生成草稿、复制材料，都不代表已经发送或执行。

用具体反馈更新理解。 回来说明哪件事、做了什么、对方如何回应、结果是否明确。已发送、已读、已回复、已采用和有效果是不同状态；不知道是否采用就直说不知道。

更正和暂停。 在原对话说明“更正：……，其他事实不变”；暂停时点明对象，例如“先暂停考研探索，不再安排相关行动”。如果出现待确认操作，核对对象后再确认。

管理长期记忆。 登录后在对话顶部打开“长期记忆”，使用“启用长期记忆”开关，核对“已开启”或“已关闭”提示。背景条目提供“更正”和“忘记”，更正后点击“保存”。认知空间和原对话用于查看目标、经历与建议边界。

关闭跨对话记忆不会同时删除可见聊天历史；当前对话仍可使用本轮上下文。不要用开关代替逐条遗忘。可以拒绝建议、否定解释、暂缓决定，或只要求倾听。

04 / 使用条件与常见问题

如何获得访问权限？ 使用已开通的邮箱账户。若页面提供“创建账户”，按页面操作；注册成功不代表已获得对话资格。若提示邀请、未开通或到期，请向作品提供者申请评审体验账号或资格。公开文档不提供密码；评委访问安排尚待单独确认。

回复较慢怎么办？ 等待最终完成，不连续点击发送。历史 a12fd22 / final89 本地真实接口测试首有效内容中位数3.27秒、95分位8.53秒，完整回复95分位17.15秒，均未达原目标。网络、供应商和问题复杂度会影响等待；这些数值不是公网承诺。

异常或刷新后如何继续？ 短时间连续发送可能触发频率限制，请按提示等待。回到原对话检查已保存的最终回复，已保存内容无需重发。没有保存成功时，不把预览当作最终结果；不确定请求是否完成时先核对状态，避免重复发送同一任务。持续无法进入时查看交付状态说明。

对话和材料存在哪里？ 登录后的正式对话保存在当前账户，刷新后从原对话继续。材料可在相应回复及事项区域查看，改写后核对最新内容。未登录的演示不等于账户正式记录；复制草稿也不等于对外发送。

如何调整节奏或记忆？ 通过“长期记忆”查看和更正背景；在对话点明要暂停或遗忘的具体事项，核对确认信息。关闭开关仅控制跨会话使用，不自动删除历史聊天。

有哪些实际限制？ 当前为受控试运行；账号资格和额度受现有配置限制。AI表达可能重复或不完全符合格式，材料需本人复核。未提供自动日程执行、自动发送消息或保证录取、就业及收入的能力。

如何判断验证范围？ 产品设计PDF保留88bd390 / final80口径；效果佐证PDF保留a12fd22 / final89口径。合成账号测试不能证明真实学生长期效果。正式运行版本与公网功能检查分别记录，不用链接可打开或文档提交替代产品验收。
